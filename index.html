Emotional Speech Benchmark

Adding emotion to a cloned voice: four approaches compared

New: Round 2 → a sentence written for each emotion, 30 library voices in English, Spanish and French

What you are listening to

Every audio says the same sentence:

"I don't understand why you did this to me! You were supposed to help me, not to destroy everything I built."

Please team, listen to each row and compare how well each approach conveys the emotion while still sounding like the reference speaker.

Qwen3-TTS emotion prompt
An emotional recording generated by Qwen3-TTS. It is not in the target speaker's voice; it is the emotion source for the next column, and is the same for both speakers.
Qwen3-TTS prompt → STS
The Qwen3-TTS prompt converted into the target speaker's voice with a speech-to-speech model.
CosyVoice3 end-to-end
Fun-CosyVoice3-0.5B cloning the reference voice directly, with the emotion given as a text instruction (e.g. "Speak in a very angry, furious tone").
Chatterbox → Step-Audio-EditX
A neutral Chatterbox clone of the speaker, then edited by Step-Audio-EditX with an emotion label (two edit passes). Step-Audio-EditX has no "shocked" or "exhausted" label, so Shocked uses surprised and Exhausted uses depressed.
